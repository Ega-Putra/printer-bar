Kebijakan Privasi — Printer Bar

Terakhir diperbarui: 19 Oktober 2026

Printer Bar ("aplikasi") adalah aplikasi Android untuk mencetak resi PDF dan gambar ke printer thermal Bluetooth. Privasi Anda penting bagi kami — aplikasi ini dirancang agar tidak mengumpulkan data pribadi apa pun.

Data yang kami kumpulkan

Tidak ada. Aplikasi ini tidak membuat akun, tidak meminta data pribadi, tidak menjalankan analitik, tidak menampilkan iklan, dan tidak mengirim data apa pun ke server atau pihak ketiga.

Berkas dan Bluetooth

  • Berkas PDF/gambar yang Anda pilih diproses sepenuhnya di perangkat Anda (render, crop, deteksi barcode, rasterisasi) dan tidak pernah diunggah ke mana pun.
  • Koneksi Bluetooth hanya digunakan untuk mengirim data cetak ke printer thermal pilihan Anda. Tidak ada data perangkat yang dibagikan ke pihak lain.
  • Izin lokasi (jika diminta) hanya digunakan oleh sistem Android untuk penemuan perangkat Bluetooth, sesuai ketentuan Android — lokasi Anda tidak dibaca, disimpan, atau dibagikan.

Berbagi data dengan pihak ketiga

Tidak ada data yang dibagikan kepada pihak ketiga mana pun.

Keamanan

Karena tidak ada data yang dikumpulkan atau ditransmisikan, tidak ada data pengguna yang berisiko bocor dari sisi kami. Berkas sementara hasil pemrosesan disimpan di penyimpanan internal aplikasi dan dapat dihapus dengan menghapus data aplikasi.

Anak-anak

Aplikasi ini tidak ditujukan untuk anak di bawah 13 tahun dan tidak mengumpulkan data dari siapa pun, termasuk anak-anak.

Perubahan kebijakan ini

Jika kebijakan ini berubah, versi terbaru akan dipublikasikan di halaman ini dengan tanggal pembaruan yang baru.
